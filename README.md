# 프드프 강의 1.5배속 다운로더

프드프([pudufu.co.kr](https://pudufu.co.kr))에서 **내가 구매한 강의**를 1.5배속 영상 파일로 저장하는 데스크톱 앱입니다.

[최신 릴리스 다운로드](https://github.com/thsvkd/pudufu-recorder/releases/latest)

## 주요 기능

- **1.5배속 저장** — 배속은 1.25 / 1.5 / 1.75 / 2.0 중에서 고를 수 있습니다. 음성은 톤이 변하지 않게 처리됩니다.
- **강의 통째로** — 강의를 고르면 전체 목차를 불러와 원하는 회차만 골라 받을 수 있습니다.
- **PART별 폴더 정리** — `강의명 / 01_PART명 / 01_회차제목.mp4` 형태로 저장됩니다.
- **이어받기** — 중간에 멈췄다가 다시 실행하면 이미 받은 회차는 건너뜁니다.
- **원본 보관(선택)** — 1배속 원본을 함께 남길 수 있습니다. 용량이 약 2배가 됩니다.
- **동시 처리** — 한 번에 최대 4개까지 병렬로 받습니다.
- **ffmpeg 자동 설치** — 영상 처리에 필요한 ffmpeg가 없으면 앱이 안내 후 자동으로 받아옵니다.

## 시작하기

### 1. 설치

[최신 릴리스](https://github.com/thsvkd/pudufu-recorder/releases/latest)에서 사용 중인 운영체제에 맞는 파일을 받으세요.

- **macOS**: `PudufuRecorder-osx-Setup.pkg`
- **Windows**: `PudufuRecorder-win-Setup.exe`

받은 설치 파일을 실행하면 설치가 진행되고, 끝나면 앱이 바로 열립니다. 이후 새 버전이 나오면 앱이 알려주고 스스로 업데이트합니다.

> **macOS에서 "Apple은 ... 악성 코드가 없음을 확인할 수 없습니다" 경고가 뜬다면**
>
> 유료 Apple 개발자 인증서 없이 배포해서 나오는 경고입니다. 아래 순서로 설치하세요.
> `.pkg` 파일은 **우클릭 → 열기가 통하지 않습니다**(macOS 15부터 막혔습니다).
>
> 1. 설치 파일을 더블클릭하면 뜨는 경고창을 **완료**로 닫습니다.
> 2. **시스템 설정 → 개인정보 보호 및 보안**을 열고 **보안** 항목까지 내려갑니다.
> 3. `Mac을 보호하기 위해 'PudufuRecorder-osx-Setup.pkg'을(를) 차단했습니다` 줄 옆의 **그래도 열기**를 누르고, 암호나 Touch ID로 인증합니다.
> 4. 다시 뜬 경고창에서 **열기**를 누르면 설치가 진행됩니다.
>
> 터미널이 편하다면 격리 표시를 지우는 것으로도 됩니다. 그 뒤 평소처럼 더블클릭하면 됩니다.
>
> ```bash
> xattr -d com.apple.quarantine ~/Downloads/PudufuRecorder-osx-Setup.pkg
> ```

### 2. 로그인

프드프 계정의 이메일과 비밀번호로 로그인합니다. 카카오 로그인만 쓰고 있다면, 프드프 웹사이트의 **My콘텐츠 → 이메일 로그인 연동**에서 이메일 로그인을 먼저 설정해야 합니다.

"로그인 정보 기억하기"를 켜면 이 기기에만 저장되고, 서버로는 전송되지 않습니다.

### 3. 강의 선택

내 강의 목록에서 강의를 고르면 목차가 나옵니다. 받을 회차를 고르고, 배속·저장 폴더를 정한 뒤 **다운로드 시작**을 누르세요.

## 작동 방식

프드프는 강의 영상을 Cloudflare Stream으로 제공합니다. 이 앱은 로그인한 세션으로 강의 페이지에서 영상 주소를 찾고, 다음 순서로 가장 빠른 소스를 선택합니다.

1. **MP4 우선** — Cloudflare에서 MP4 다운로드가 활성화되어 있으면 단일 MP4를 사용합니다.
2. **HLS 자동 전환** — MP4가 없거나 받을 수 없으면 HLS 원본 스트림으로 즉시 전환합니다.
3. **경로별 최적 처리** — MP4는 HTTP 응답을 그대로 저장하고, HLS는 기본 설정에서 내려받는 동시에 `setpts` / `atempo` 필터로 변환합니다. macOS에서는 하드웨어 인코더를 사용합니다.

"원본도 함께 보관"을 켠 경우에만 원본 파일을 먼저 완성한 뒤 배속 영상을 만듭니다. 화면 녹화가 아니므로 강의 길이만큼 기다릴 필요가 없습니다.

## 소스에서 실행하기

```bash
git clone https://github.com/thsvkd/pudufu-recorder.git
cd pudufu-recorder

uv sync
uv run python main.py
```

`.env`에 계정을 넣어두면 로그인 화면이 미리 채워집니다.

```
PUDUFU_ID=your@email.com
PUDUFU_PW=your-password
```

GUI 없이 쓰려면 CLI도 있습니다.

```bash
uv run python cli.py --list                       # 내 강의 목록 보기
uv run python cli.py --course-id 686 --speed 1.5  # 강의 전체 받기
```

## 자주 묻는 질문

**받는 데 얼마나 걸리나요?**
14시간 분량 강의 기준으로 약 1시간 안팎입니다(동시 처리 2개, 네트워크 환경에 따라 다릅니다).

**용량은 얼마나 되나요?**
1080p 강의 기준 시간당 약 1.5~2GB입니다. "원본도 함께 보관"을 켜면 약 2배가 됩니다.

**받다가 껐어요.**
다시 실행하고 같은 강의를 고르면 됩니다. 이미 받은 회차는 건너뜁니다.

**"재생시간 정보 없음"으로 나와요.**
프드프가 강의에 따라 재생시간을 표시하지 않습니다. 받는 데는 문제가 없습니다.

## 주의

본인이 구매한 강의를 **개인 학습 목적으로** 저장하기 위한 도구입니다. 저장한 영상을 재배포하거나 공유하는 것은 저작권 침해에 해당할 수 있으며, 그로 인한 책임은 사용자에게 있습니다.
